# AI Commit UI 重构任务列表

## 项目概述
将AI generate和用户手动构建commit message的行为分开，通过选项卡的方式提供更好的用户体验。

## 核心需求
1. 将AI generate和用户手动构建commit message的行为分开，他们之间互不影响，例如分成两个选项卡
2. 如果设置中AI功能可用，那么默认选中AI generate选项卡
3. 选中AI generate后，AI生成的提交信息(commit message)直接显示在面板上，用户可以编辑，修改
4. 无论是AI generate还是手动构建提交信息，当触发了CreateCommitAction中的DialogWrapper.OK_EXIT_CODE点击事件时，都能将提交信息传递给commitPanel

## 风险评估

### 高风险
- UI重构可能影响现有功能的稳定性
- AI生成功能与现有代码的集成复杂度较高

### 中风险
- 数据流重构可能引入新的bug
- 用户体验的改进效果需要用户反馈验证

### 低风险
- 配置和设置功能的实现相对简单
- 错误处理机制的实现较为直接

## 成功标准

1. 用户可以在AI生成和手动构建之间无缝切换
2. AI生成功能稳定可靠，错误处理完善
3. 现有功能完全保留，无回归问题
4. 用户体验明显改善，操作更加直观
5. 代码结构清晰，易于维护和扩展
