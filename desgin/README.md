# AI Commit Message Helper 设计文档

## 项目概述

本项目旨在为现有的Git Commit Message Helper插件添加AI自动生成commit message功能，利用DeepSeek的OpenAPI服务，分析本地代码变更内容，自动生成符合规范的commit message。

## 核心功能特性

### 🚀 AI自动生成
- 基于DeepSeek AI模型
- 智能分析代码变更
- 自动生成符合规范的commit message

### ⚙️ 灵活配置
- 支持自定义API设置
- 可配置生成参数
- 支持多种AI模型

### 🎨 用户友好
- 无缝集成现有界面
- 实时状态反馈
- 支持手动编辑和优化

### 🔒 安全可靠
- API密钥加密存储
- 本地代码分析
- 隐私保护机制

### 🌍 国际化支持
- 多语言界面
- 本地化适配
- 符合国际标准

## 技术栈

### 后端技术
- **Java 11+**: 主要开发语言
- **IntelliJ Platform SDK**: 插件开发框架
- **OkHttp**: HTTP客户端
- **JSON**: 数据交换格式
- **Velocity**: 模板引擎

### 前端技术
- **Swing**: UI框架
- **IntelliJ UI Components**: 原生组件
- **CSS**: 样式定义

### 外部服务
- **DeepSeek API**: AI服务提供商
- **Git**: 版本控制系统
